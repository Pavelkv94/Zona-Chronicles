Статус: working prototype, Milestone B в работе

## 1. Что мир делает сегодня

Мир идёт сам. Ни одна из перечисленных ниже вещей не требует команды человека.

- **время движут события, а не тик.** Такт обрабатывает ОДИН момент мирового времени; между
  событиями не происходит ничего, и это доказано исполнением — сутки мирового времени без
  вмешательства не добавляют в журнал ни одной записи;
- **у агентов есть тело.** Голод и усталость — производные величины: канон хранит момент отсчёта,
  значение считает чистая функция, а фактом является пересечение порога;
- **агент выбирает цель сам.** `score(goal) = urgency - time_cost - switching_cost`, целые
  тысячные, коэффициенты в versioned ruleset. Кандидаты: `idle`, `eat`, `rest`, `flee`.
  Исполнимость входит в отбор, ничья решается порядком объявления;
- **план может сорваться, и мир чинит себя сам.** У плана есть тождество; невыполненное
  предусловие даёт `plan.invalidated`, а прерванное занятие заканчивается ничем — платы за
  несделанную работу нет;
- **у мест и дорог есть опасность, у агентов — осторожность**, разыгранная в генезисе из seed;
- **решение принимается по тому, что агент ЗНАЕТ, а не по тому, что есть в мире.** Знание о
  дороге входит в мир фактом `risk.observed` с провенансом; незнание выражено отсутствием записи
  и стоит `assumedUnknownRiskPermille`, а не запретом;
- **зритель видит мир в браузере**: карта, карточки агентов, лента фактов, живой поток SSE.
  Экран называет решение, дорогу и факт разведки — и не показывает ни опасности, ни разбора
  оценок, ни чужой памяти;
- **мир переживает перезапуск**: replay из журнала даёт побайтово тот же результат, проекция
  догоняет ровно один раз на событие, потеря окна retention сообщается зрителю явно.

**Наблюдаемая демонстрация последней итерации:** два одинаковых агента в одинаковом положении
уходят от опасности РАЗНЫМИ дорогами, и различие объясняется тем, что один из них видел, а
другой нет.

### Чего мир НЕ делает

Названо здесь, чтобы не приходилось выяснять это запуском:

- **еда конечна и ничем не восполняется.** Источника предметов нет (I08), поэтому за двое суток
  прототипного мира все агенты приходят к «голоден, еды нет» и остаются в нём. Это граница
  симуляции, а не дефект;
- **план длиной один шаг.** «Пойти туда, где еда» построить не из чего;
- **маршрут длиной один шаг.** Агент выбирает дорогу, а не путь через несколько локаций;
- **встреч нет.** Агенты проходят друг сквозь друга: обнаружение, избегание и контакт — I06B;
- **угрозы неподвижны.** Существа, аномалии и погода — I06C и позже;
- **пересказа, лжи и доверия к источнику нет.** У знания один источник — `witnessed`; поле
  `source_type` намеренно не введено, чтобы не заморозить форму пересказа раньше решения (I10A);
- **ни одной строки от LLM.** До Gate E запрещены runtime SDK, ключи, промпты, embeddings и
  очереди генерации (ADR-006).

## 4. Названные и НЕ отданные долги

Здесь только то, что известно и записано. Долг, о котором никто не знает, в список не попадает —
и это причина, по которой список ведётся.

**Контроль и harness**

- **`write_paths` ничего не гарантирует.** Роль read-only держится тем, что у сессии отключён
  инструмент `Write`; Bash пишет свободно, в том числе в дерево, из которого hook берёт
  `projectRoot`. Проверено действием: `exit=0` при объявленных `"write_paths": []`;
- **атрибуция правок ломается в общем дереве.** Hook берёт корень из `input.cwd`, а subagent
  наследует его от родителя, поэтому правки lead-а приписываются ревьюеру. Пока это так, lead не
  должен писать в общее дерево при открытой задаче ревью;
- **`pnpm verify` в task-worktree падает на `format:check`**: `task:worktree` коммитит
  `.claude/writeset.json` неформатированным. Ревьюер не может прогнать gate той же командой, что
  lead;
- **`await migrated.close()` в `afterAll` без охраны** (большинство integration-файлов): при
  падении `beforeAll` поверх настоящей ошибки прилетает `TypeError`, и в хвосте лога человек
  видит именно её. Дважды стоило потерянного текста отказа. Починка — `?.`;
- **ненулевой `skipped` — часть вердикта.** `.skip` в коде нет ни одного, поэтому `skipped`
  означает сломанный suite-хук, а не пропуск.

**Тесты и доказательства**

- **верхняя сторона темпа не покрыта.** Снятая граница по настоящим часам была плохим
  утверждением, но единственным, ловившим «мир идёт БЫСТРЕЕ объявленного темпа». Равенство в
  мировом времени этого не видит. Закрывать надо в тех же единицах;
- **у I06 нет acceptance-ТЕСТА** (исполняемого, через CLI), хотя он есть у I01–I05. Документ
  `ACCEPTANCE.md` у неё теперь есть — это разные вещи, и путать их не следует: демонстрация
  итерации живёт в `flee.integration.test.ts` и в e2e;
- **граница длины маршрута не доказана.** `GOAL_SCORE_BOUNDS` выведен под допущением
  `travelMinutes <= MAX_GOAL_DURATION_MINUTES`, которого продукт не требует;
- **отказ `too many clients already` в цепочке gate**: форма известна, причина исчерпания — нет.
  Один прогон берёт 14 соединений из 100, значит нужен внешний потребитель. Локальный предел
  поднят до 300, CI оставлен на умолчании, расхождение названо в `ci.yml`.

**Механика**

- **emergency interrupt на коэффициентах прототипа не наступает.** Механизм проверен на
  построенной истории; за четырнадцать мировых суток совпадение «предел голода во сне» не
  случилось ни разу;
- **порог смены цели на прототипных коэффициентах ни одного решения не меняет.** Механизм живой
  и проверен поведением на других коэффициентах;
- **осторожность не влияет на выбор дороги, пока не разведана ни одна дорога** — воспринимаемый
  риск у всех дорог общий и в сравнении сокращается. Это названный предел, закреплённый тестом;
- **обновления знания нет.** Первое наблюдение остаётся навсегда: устаревание — вопрос I10A, и до
  решения два слоя не имеют права кодировать разные ответы.

## 5. Как убедиться самому

```sh
docker compose up -d postgres        # база
pnpm install --frozen-lockfile
pnpm verify                          # быстрый gate
pnpm verify:full                     # полный, нужен Docker
```

Живой мир локально:

```sh
DATABASE_URL=... node apps/cli/src/main.ts world migrate
DATABASE_URL=... node apps/cli/src/main.ts world init --seed 42
# worker (темп), api (3001), web (3100) — переменные см. в docs/03_TECHNICAL_DESIGN
```

Последний наблюдённый полный gate:

```
805 unit · 49 property · 502 contract · 162 integration · 5 replay · 58 acceptance · 5 e2e
```

Числа обязаны совпадать с заявленными в последнем коммите итерации. Расхождение — повод
разбираться, а не обновлять цифру здесь.
