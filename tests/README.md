# tests

Кросс-пакетные наборы, которые не принадлежат одному workspace-пакету.

| Каталог        | Что содержит                                                            | Итерация |
| -------------- | ----------------------------------------------------------------------- | -------- |
| `acceptance/`  | вертикальные acceptance-тесты итераций (владелец — `acceptance-author`) | I02A+    |
| `replay/`      | snapshot + suffix = полный replay, детерминизм прогонов                 | I02B     |
| `integration/` | кросс-пакетные сценарии на настоящем PostgreSQL                         | I02A+    |
| `contract/`    | кросс-пакетные contract-тесты                                           | I03+     |
| `soak/`        | длительные многосидовые прогоны                                         | I15B     |
| `e2e/`         | Playwright-маршруты наблюдателя                                         | I03+     |

`acceptance/` и `replay/` — protected paths: их изменяет только владелец задачи по
`08_TDD_AND_AGENT_WORKFLOW` §12.1.

`pnpm test:replay` вызывается с `--passWithNoTests`, потому что набор пуст до I02B.
Флаг стоит в скрипте, а не в конфиге, чтобы допущение было видно в месте вызова.
Для остальных проектов пустой набор считается ошибкой.
